# @hydrooj/user-list

加强的用户管理一站式面板(`/user-list`)。

## 功能

- 全局搜索用户(UID / 用户名 / 邮箱),分页浏览;
- 查看用户完整信息,并直接:
  - 修改用户名 / 邮箱 / 学校 / 手机号 / 简介;
  - 重置密码(可指定或自动生成随机密码并一次性展示);
  - 勾选式编辑全局权限(PRIV 位:判题、读题面数据、管理系统等全部细粒度开关);
  - 封禁 / 解封(可填写封禁原因);
  - 查看用户所有域成员身份,调整每个域的角色与加入状态。
- 所有操作写入系统操作日志(Oplog)。

## 权限

入口即校验 `PRIV_EDIT_SYSTEM`(超级管理员)。域管理员仍使用原有 `/domain/user` 页面管理本域成员。

## 安装

将 `@hydrooj/user-list` 加入 `~/.hydro/addon.json`(或 `hydrooj addons install`),重启服务后访问 `/user-list`。
